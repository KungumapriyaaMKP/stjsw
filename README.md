# St. Joseph's Matriculation Higher Secondary School, Tirupur

Official website for **St. Joseph's Matriculation Higher Secondary School**, located at 35, Kangayam Road, Tirupur – 641604, Tamil Nadu, India (Established 1965 | Motto: *"Shine and Let Shine"*).

## Tech Stack
- **Framework**: Next.js 15 (App Router, Static Pre-rendering)
- **Styling**: Tailwind CSS v4
- **Typography**: `Cormorant Garamond` (Editorial Serif) & `Plus Jakarta Sans` (Humanist Sans)
- **Icons**: `lucide-react`

## Pages & Routes
- `/` — Homepage (Full-Viewport Campus Slideshow, Key Metrics, About Us & 1965 Legacy, Academic Continuum KG to XII, Contact & Admissions Inquiry Form, Google Map)
- `/achievements` — State Board Examination Toppers (Class XII & Class X) & Subjectwise Achievers Roll of Honour
- `/gallery` — Student-Centric Amenities, Laboratories, Smart Classrooms & Interactive Architectural Showcase
- `/alumni` — JOSATS (St. Joseph's Old Students' Association, Tirupur) Initiatives & Reunion Gallery

## Local Development

```bash
npm install
npm run dev
```

## Production Build & Start

```bash
npm run build
npm run start
```

## Deployment (Vercel / Netlify / Node Server)
1. Push this repository to GitHub / GitLab.
2. Import the project into **Vercel** (or Netlify / Railway).
3. Framework preset is automatically detected as **Next.js** (`npm run build`).
4. Deploy with zero additional configuration required.
